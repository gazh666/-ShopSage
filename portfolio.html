项目概览

一个「Agent-first」的电商导购系统，覆盖用户侧 AI 导购、真实商品召回、加购下单闭环、商家履约、管理员观测与质量测评全链路。

01

多模态输入

文本导购、图片找同款、语音输入与 TTS 播报统一接入。

02

真实业务闭环

商品库、购物车、订单、优惠、评价、知识库全打通。

03

可观测排障

意图、Prompt、工具调用、RAG 片段全链路追踪可视化。

04

质量测评

意图识别、RAG 召回、Agent 端到端报告与明细。

二次开发亮点

相对原始电商底座，本次工程化增强聚焦「规划、执行、校验、恢复、评估」五个维度。

Highlight 01

Agent 任务规划与容错

引入 ReAct / Plan-and-Solve，实现任务拆分、子任务结果校验、工具调用重试与降级，让复杂导购请求可被分步可靠执行。

Highlight 02

上下文分层管理

把上下文拆为任务状态、短期对话、用户长期记忆、外部检索信息四类独立存储，并落地用户偏好持久化。

Highlight 03

导购任务规划流水线

TaskPlanner / TaskExecutor / ResultVerifier / TaskStateManager / TraceAdapter 五模块：复杂请求自动进入流水线，简单 query 走原单轮 Agent，支持中断断点恢复。

Highlight 04

工业级工程化

前后端独立多阶段 Dockerfile、docker-compose 全栈编排、统一 Makefile、GitHub Actions CI，一键拉起即可演示。

任务规划流水线

复杂导购请求从任务初始化到完成的完整状态机，主任务与子任务状态均持久化到数据库，支持中断后断点恢复。

子任务按依赖顺序串行调度，工具执行后经「规则校验（预算/库存/品类）+ 轻量模型校验（主观约束）」双重把关；校验失败自动重试，多次失败进入降级分支并动态重规划。
